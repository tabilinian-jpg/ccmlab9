## Mission Overview

Secure an Ubuntu web server by establishing a baseline, enabling UFW with a default-deny inbound policy, and allowing only the client-required SSH and TCP 8080 traffic.

## Objectives

- Explain least privilege, attack surface, and default-deny security.
- Configure and verify UFW rules for SSH and the web application.
- Record terminal evidence and reflect on host firewall and port security.
